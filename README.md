# Order Management UI App

A modern Flutter UI application for managing customer orders.

## Features

* Modern Dashboard UI
* Responsive Design
* Orders List with Mock Data
* Add New Order Screen
* Clean Navigation
* Material 3 Design
* Reusable Widgets
* Organized Project Structure
* Smooth User Experience

## Screens

### Dashboard Screen

* Total Orders Card
* Orders In Progress Card
* Orders List
* Floating Action Button

### Add Order Screen

* Customer Name Field
* Product Type Dropdown
* Delivery Date Picker
* Order Details Field
* Save Order Button



## Technologies Used

* Flutter
* Dart
* Material 3



## Notes

* This project contains UI only.
* No Firebase or Backend integration.
* No APIs used.
* All data is hardcoded mock data.
